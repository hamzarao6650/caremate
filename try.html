How it works

Grounded in each resident's normal.

A generic chatbot would only reword the note. CareMate AI checks every line against the resident's own baseline and care plan before it writes anything.

Read the note

Handles shorthand like "bs", "q2h" and "c/o", typos and several residents in one note.

Find the baseline

Matches each name to a resident profile in the knowledge base and pulls their normal and care plan triggers.

Grade each change

Sorts every change into Routine, Watch, Notify nurse now or Emergency, and flags required checks that are missing.

Write the outputs

An SBAR handoff for the next shift, a list of what needs attention now and family drafts that match each family's wishes.

RoutineSame as the resident's baseline.
WatchA small change. The next shift rechecks.
Notify nurse nowA care plan trigger, a fall, new confusion or a missing check.
EmergencyFollow the emergency policy and call 911.

How we built it: an AI agent in Chatling, grounded in a knowledge base we wrote: six resident profiles, an SBAR handoff standard with four change levels and a family update guide. Its instructions set the output format and the safety rules below.

Limits and safety

A draft for staff, never a decision.

What it does

  • Turns a free-text note into a structured handoff
  • Compares each change with the resident's baseline
  • Flags care plan triggers and missing checks
  • Drafts family updates in plain, warm language

What it does not do

  • Diagnose, suggest medicines or change a care plan
  • Use or store real resident information
  • Send anything to families on its own
  • Replace the nurse's judgment

This demo runs on a free plan with a limited number of answers each month. If it stops replying, please try again later.
